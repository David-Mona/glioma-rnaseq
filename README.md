# Glioma Rna-seq: IDH-mutant vs IDH-wildtype

## Objective: Differential expression analysis of TCGA-LGG (Low grade glioma) and TCGA-GBM (Glioblastoma) RNA-seq data

- IDH (isocitrate dehydrogenase) mutations produce 2-hydroxyglutarate, which leads to widespread DNA hypermethylation (G-CIMP) and changes in gene expression.

- This project:

1.  Reproduces the known expression differences associated with IDH status (validation);
2.  Explores extracellular matrix genes, focusing on Tenascin-C (TNC).
